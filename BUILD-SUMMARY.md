## 🎨 Design System Details


### Shadow System
```css
Raised Elements:
- Light Shadow: 0 8px 16px rgba(255, 255, 255, 0.8)
- Dark Shadow: 0 8px 16px rgba(0, 0, 0, 0.15)

Inset Elements:
- Light Inset: inset 0 4px 8px rgba(255, 255, 255, 0.6)
- Dark Inset: inset 0 4px 8px rgba(0, 0, 0, 0.1)
```

- **Headings**: Montserrat (Bold, Geometric)
- **Body**: Inter (Clean, Modern)

## 🎯 How to Use

### Getting Started
1. **Clone the repository**
   ```bash
   git clone https://github.com/mompatimasiangoako-prog/100-projects-neumorphic-book.git
   ```

2. **Open in browser**
   ```bash
   cd 100-projects-neumorphic-book
   open index.html
   ```

3. **Or use local server**
   ```bash
   python -m http.server 8000
   # Visit http://localhost:8000
   ```

### Add Your First Project
1. Click on any project card
2. Fill in project details:
   - Title
   - Description
   - Upload screenshot
   - Add skills
   - Write what you learned
   - Add rating
   - Mark as completed
3. Click "Save Project"
4. Data saved automatically to localStorage

### Navigate
- Use the **bottom navigation bar** to move between pages
- Use **← Previous** and **Next →** buttons to navigate
- Click **Table of Contents** to go to projects page
- Press **keyboard arrows** to navigate
- Click **THEME** to toggle dark mode

### Export/Backup
- Right-click → Developer Console
- Type: `ProjectsBook.ExportUtils.exportJSON()`
- Download your projects as JSON

## 🎨 Customization Guide

### Change Accent Color
Edit `css/neumorphic.css`:
```css
:root {
    --color-accent: #YOUR_COLOR;
}
```

### Change Background Color
```css
:root {
    --color-bg-primary: #YOUR_COLOR;
}
```

### Add New Pages
1. Add page in `index.html`
2. Add button in navigation
3. Add route in `js/app.js`
4. Style in CSS files

### Adjust Animation Speed
```css
--transition-fast: 150ms;    /* Adjust here */
--transition-base: 250ms;
--transition-slow: 350ms;
```
